## Long description

ReCircle is the first Shopify theme purpose-built for **refurbished, pre-owned, and circular-economy** merchants. Whether you sell refurbished electronics, pre-loved fashion, or restored furniture, ReCircle gives you the eight features every recommerce store needs — without installing a single app.

### 8 refurbished-specific features no other theme has

- **Condition grading** — A/B/C/D badges on every product card, filterable in collections.
- **Trade-in calculator** — merchant-editable pricing table (brand + condition + age), live quote inline.
- **Digital Product Passport block** — ESPR-ready materials, origin, traceability. EU mandate 2026–2027.
- **Repairability score** — 0–10 ring with spare-parts availability.
- **CO₂ savings counter** — per-product badge + site-wide tally.
- **Before / after refurbishment gallery** — hand-slider comparison.
- **Warranty bar** — months + description, prominent on product page.
- **Dual-price display** — "€499, you save €200 vs new" (EU Price Indication Directive).

### EU-compliance by default

- **6 EU languages** — EN, DE, FR, IT, ES, NL translated out of the box.
- **Shopify Markets ready** — geo-aware currency + country selector in the header.
- **WCAG 2.2 AA** — skip link, visible focus ring, focus traps, aria-live updates, `prefers-reduced-motion`. (EAA June 2025.)
- **GDPR-safe** — no third-party scripts, no external fonts. All data stays in Shopify.

### 3 niche demos, one theme

Switch your homepage template in one click:

- **Electronics** — phones, laptops, tablets. Battery health, cycle count, data-wipe certified.
- **Fashion** — authenticated pre-loved apparel. Designer + high-street.
- **Furniture** — restored mid-century + appliances. White-glove delivery.

### Performance that sells

- Vanilla JavaScript, no framework bloat. Total JS under 100 KB.
- Single CSS file, preloaded, non-render-blocking.
- Responsive `srcset` on every image.
- AJAX cart drawer + predictive search — no full-page reloads.

### Merchant-friendly

- Full theme-editor customisation — colors, type, sections, blocks.
- 10+ custom sections, each with presets.
- 17 pre-defined metafields — set up once, USPs populate automatically.
- No build step. No node_modules. Upload the zip and you're live.
